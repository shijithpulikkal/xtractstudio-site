PYTHON GOOGLE CLOUD BIGQUERY DATA STUDIO

Instacart Ads Retail Media Pipeline

  • Instacart's Ads API has no native BigQuery export — retail media performance data was trapped behind manual CSV pulls. I built 3 independent Cloud Run jobs that authenticate via OAuth2, pull campaign, keyword, and product-level performance from Instacart's async reporting API, and load it into BigQuery on a daily schedule.
  • Then I engineered idempotent backfill logic to auto-chunk 7+ months of historical data into monthly batches, with a shared, self-rotating OAuth token across all three jobs via Secret Manager. Outcome: fully automated daily reporting, zero manual intervention, running at $0/month on GCP's free tier, powering a live Looker Studio dashboard for a US retail media client.
